# Plan: Add `list` Subcommand to R2 CLI

## Goal
Extend existing `cloudflare_r2` CLI (which currently has `upload`) with `list` subcommand to enumerate objects in an R2 bucket, paginating through S3 `ListObjectsV2`. Keep `upload` behavior unchanged.

## Current State (from previous execution)
- `Cargo.toml` already has `clap[derive,env]`, `tokio[full]`, `aws-sdk-s3`, `aws-config[behavior-version-latest]`, `anyhow`, `mime_guess`, `dotenvy`
- `src/main.rs` implements `Cli { upload }` with `derive_endpoint`, `build_client`, `upload`. Tests 7 pass, `cargo clippy -D warnings` clean, `cargo fmt` clean.
- `README.md` documents upload. Binary builds to `target/release/cloudflare_r2`.

## Proposed Change (scoped)

### CLI Design
```rust
#[derive(Subcommand)]
enum Commands {
    Upload(UploadArgs),
    List(ListArgs),
}

#[derive(Parser)]
struct ListArgs {
    #[arg(short, long, env="R2_BUCKET")] bucket: String,
    #[arg(long)] prefix: Option<String>, // e.g. "images/"
    #[arg(short, long)] long: bool, // detailed: size + last_modified
    #[arg(long, env="R2_ACCOUNT_ID")] account_id: Option<String>,
    #[arg(long, env="R2_ENDPOINT")] endpoint: Option<String>,
    #[arg(long, env="R2_ACCESS_KEY_ID", hide_env_values=true)] access_key: String,
    #[arg(long, env="R2_SECRET_ACCESS_KEY", hide_env_values=true)] secret_key: String,
}
```

Invocation:
```bash
cloudflare_r2 list --bucket my-bucket
cloudflare_r2 list --bucket my-bucket --prefix images/ --long
cloudflare_r2 list --bucket my-bucket --endpoint https://xxx.r2.cloudflarestorage.com
R2_BUCKET=my-bucket cloudflare_r2 list --long --verbose
```

### Implementation Steps
1. **Edit `src/main.rs`** (single file, ~150 new LOC):
   - Update `Cli` about to "Upload and list files on Cloudflare R2"
   - Add `ListArgs` + `Commands::List`
   - Extend `match cli.command` with `List` arm: derive endpoint, build client, call `list_objects`
   - Add `async fn list_objects(client, bucket, prefix, long, verbose)`:
     ```rust
     let mut token: Option<String> = None;
     loop {
       let mut req = client.list_objects_v2().bucket(bucket);
       if let Some(p)=prefix { req=req.prefix(p); }
       if let Some(t)=token.take() { req=req.continuation_token(t); }
       let resp = req.send().await.context("list_objects failed...")?;
       for obj in resp.contents() {
         if long { println!("{}\t{}\t{}", key, size, modified) } else { println!("{}", key) }
       }
       if resp.is_truncated()==Some(true) { token=resp.next_continuation_token().map(|s| s.to_string()); } else { break; }
     }
     ```
     Handles pagination, empty bucket (verbose hint), respects `is_truncated` + `next_continuation_token`.
   - Reuse `derive_endpoint` + `build_client` (no new deps).
   - Add tests: `test_cli_parses_list`, `test_cli_parses_list_with_prefix_and_long`.

2. **No Cargo.toml change** (reuse existing deps). If needed, add `aws-smithy-types` explicitly for DateTime fmt (already transitive via aws-sdk-s3).

3. **Update `README.md`**: Add List section, env table already covers bucket/creds, add `list` examples.

- Endpoint/region same as upload, no new auth path.
