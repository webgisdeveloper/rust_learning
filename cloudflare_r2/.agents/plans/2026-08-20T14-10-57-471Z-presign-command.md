# Plan: Add `presign` Command (Presigned URLs)

## 1. Goal and Assumptions

**Goal:** Add `cloudflare_r2 presign <KEY> [--expires SECS] [--method get|put]` to generate SigV4 presigned URLs for R2 without network I/O. Enables sharing private objects and browser-direct PUT without leaking `R2_SECRET_ACCESS_KEY`.

**Scope — Presign Alone:**
- Single key, default `GET`, `--expires` 1..604800 (S3 7-day max), optional `--content-type` for PUT
- Human output: single URL on stdout; `-v` to stderr
- No new binary dependencies beyond `aws-sdk-s3` presigning (local crypto, no `HeadObject` check)
- No changes to `upload`/`list`/`download`/`delete`/`stat`

**Assumptions:**
- R2 SigV4 query signing = S3 (`aws-sdk-s3` `PresigningConfig`); region `auto` (`src/r2.rs:256`), endpoint precedence `R2_ENDPOINT` > `R2_ACCOUNT_ID` (`src/r2.rs:209-227`) reused
- `presigned()` is local; does not validate key existence — 404 at use time is correct
- No `--json` in v1 (single URL line is script-friendly; can add later)
- Credentials via `R2Args` flatten (`src/cli.rs:41-57`) with `env=` and `hide_env_values`

### Step 3 — Core: `src/r2.rs`
```rust
use aws_sdk_s3::presigning::PresigningConfig;
use std::time::Duration;

pub async fn run_presign(args: PresignArgs, verbose: bool) -> anyhow::Result<()> {
    let key = args.key.trim();
    if key.is_empty() { bail!("object key must not be empty"); }
    if args.method == "put" && args.expires > 604800 { /* already clamped by clap */ }
    let endpoint_url = endpoint_for(&args.r2)?;
    if verbose { eprintln!("Endpoint: {}\nBucket: {}\nKey: {}\nExpires: {}s\nMethod: {}", endpoint_url, args.r2.bucket, key, args.expires, args.method); }
    let client = build_client(&endpoint_url, &args.r2.access_key, &args.r2.secret_key).await;
    let cfg = PresigningConfig::builder().expires_in(Duration::from_secs(args.expires)).build()
        .context("invalid expires")?;
    let url = match args.method.as_str() {
        "get" => client.get_object().bucket(&args.r2.bucket).key(key).presigned(cfg).await
            .context("presign failed — check bucket, key, credentials, endpoint")?.uri().to_string(),
        "put" => {
            let mut req = client.put_object().bucket(&args.r2.bucket).key(key);
            if let Some(ct) = args.content_type { req = req.content_type(ct); }
            req.presigned(cfg).await.context("presign failed — ...")?.uri().to_string()
        },
        _ => unreachable!("clap value_parser restricts"),
    };
    println!("{url}");
    if verbose { eprintln!("Presigned {} s3://{}/{} ({}s)", args.method.to_uppercase(), args.r2.bucket, key, args.expires); }
    Ok(())
}
```
- No `HeadObject`/`GetObject` call; no `head_stat` reuse.
- For `PUT` with `content_type`, the signed header must match `curl -H "Content-Type: ..."`.

## 5. Risks, Open Questions, Rejected Alternatives

**Risks & Mitigations:**
| Risk | Likelihood | Mitigation |
|---|---|---|
| `PresigningConfig` feature not enabled in `aws-sdk-s3 1.140` → `cargo check` fails | Low | Cargo.toml already uses `aws-sdk-s3 = "1"` (default features include presigning); if fails, add `features=["presigning"]` — 1-line. |
| PUT presign without matching Content-Type header → `SignatureDoesNotMatch` | Medium | Document: `curl -H "Content-Type: …"` must match `--content-type`; code passes through `content_type` into `put_object()` before `presigned()`. |
| Clock skew invalidates URL | Low | Document 5-min skew warning; no code fix. |
| URL leaks secret if logged | Low | Print URL to stdout only; verbose to stderr; README warns not to commit URL. |
| Clap range vs manual `bail!` divergence | Low | Keep both: clap range for UX + `bail!` fallback for library call. |

**Open Questions (non-blocking):**
- Add `--json` for machine output? Defer — single-line URL is `$(...)`-friendly; add in follow-up if needed.
- Support `--expires` as `1h`/`10m` human format? Defer — `u64` seconds is S3-native, easy.
- Presign for `head` (HEAD method)? S3 `HeadObject` presign exists but rare; defer.

**Rejected Alternatives:**
| Alt | Why |
|---|---|
| Call `HeadObject` to validate existence before presign | Wastes 1 RTT; presign is local by design; URL correctly 404 at use time. |
| Implement `--method head` now | Low demand; GET covers case; add when requested. |
| Add `serde_json` URL wrapper for v1 | Overkill; stdout URL is primary; JSON can be added without breaking stdout. |
| Custom SigV4 implementation instead of `PresigningConfig` | Reinvents `aws-sdk-s3` battle-tested signing; no benefit. |
| Separate `presign-get`/`presign-put` subcommands | `—method` flag is more Clap-idiomatic; single command mirrors `aws s3 presign`. |
